# What changed — opener

Below is everything that changed in the reader's lenses this week: new cited claims per lens, open questions, and any
proposed changes to a lens's frameworks that wait for their approval.

Write the opener for their Sunday email, in Markdown:
- `## The week in three shifts` — exactly three bullets, the three changes that matter most across all lenses, each
  1–2 plain-English sentences (what moved and why it matters). Only use what's below; no outside knowledge.
- If any frameworks proposals are listed, one closing line: `**Waiting for your OK:** <n> proposed frameworks change(s)
  — see each lens below.`

Nothing else: no preamble, no sign-off, no code fences.
